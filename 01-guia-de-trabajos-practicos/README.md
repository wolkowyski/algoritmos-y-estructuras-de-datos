# Guía de Trabajos Prácticos

La guía de la cátedra resuelta, unidad por unidad. Cada archivo tiene la consigna como comentario arriba de cada resolución.

| Unidad | Contenido |
|---|---|
| [`0-algoritmos`](0-algoritmos) | Acciones, estados iniciales y finales, asignaciones y primeros algoritmos |
| [`1-elementales`](1-elementales) | Datos elementales, estructuras secuenciales, condicionales y repetitivas (1.1.1 a 1.1.36) y subacciones |
| [`2-secuencias-y-archivos`](2-secuencias-y-archivos) | Secuencias de datos elementales, archivos secuenciales, corte de control, mezcla, actualización secuencial y archivos indexados |
| [`3-arreglos`](3-arreglos) | Arreglos y matrices, recorridos, búsqueda, ordenamiento y procesos estadísticos |
| [`4-listas`](4-listas) | Operaciones básicas y ejercicios 4.2 a 4.8 (simples, dobles y circulares) |
| [`5-recursividad-y-arboles`](5-recursividad-y-arboles) | Árbol de expresión, recorridos y funciones recursivas sobre árboles y arreglos |

Los archivos que terminan en `-teoria` son resúmenes de clase con el esquema general de cada técnica. Los ejercicios 4.9 a 4.14 están resueltos en [`../04-desafios-y-practica/ejercicios-discord`](../04-desafios-y-practica/ejercicios-discord).
